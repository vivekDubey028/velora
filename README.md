# Velora Technologies

Welcome to the future of digital experiences. Velora is a high-performance web landing page built with React, TypeScript, and Vite, featuring a premium custom design system.

## ✨ Features

- **🚀 Performance**: Powered by Vite for lightning-fast HMR and build times.
- **💎 Premium Design**: Custom glassmorphism-inspired UI with a sleek dark theme.
- **📱 Responsive**: Fully optimized for mobile, tablet, and desktop viewports.
- **🎨 Typography**: Integrated with Google Fonts (Outfit and Inter).
- **SEO**: Pre-configured meta tags and semantic HTML structure.

## 🛠️ Tech Stack

- **Framework**: React 18+
- **Build Tool**: Vite
- **Language**: TypeScript
- **Styling**: Vanilla CSS with Modern Variables

## 🏗️ Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Start development server**:
    ```bash
    npm run dev
    ```

3.  **Build for production**:
    ```bash
    npm run build
    ```

## 📂 Project Structure

- `src/assets/`: Brand assets and images.
- `src/App.tsx`: Main page layout and components.
- `src/index.css`: Global design system and theme variables.
- `src/App.css`: Page-specific component styling.
